# Local Repo — Web Dev Practice Project
 
A personal project to practice and improve frontend web development skills using HTML, CSS, and JavaScript.
 

 
## About
 
This is a hands-on learning project where I experiment with web technologies, try out new concepts, and build things as I grow my skills as a developer.


 
## Tech Stack
 
- **HTML5** — Page structure and semantics
- **CSS3** — Styling and layout
- **JavaScript** — Interactivity and logic
- **Bootstrap** — CSS framework for responsive design


 
## What I'm Learning

- Writing clean HTML structure and CSS styling
- Making webpages look good on mobile, tablet and desktop
- Using Bootstrap to design faster and easier
